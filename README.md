# Photo Booth · ARIT PSRU (เวอร์ชัน Sony Handycam)

ตู้ถ่ายภาพฉากเขียวสำหรับงานพระราชทานปริญญาบัตร มหาวิทยาลัยราชภัฏพิบูลสงคราม
ให้บริการโดย สำนักวิทยบริการและเทคโนโลยีสารสนเทศ — ออกแบบตามแบบ `Photo Booth v3` (IBM Plex Sans Thai, ธีมสีโลโก้ ARIT)

เวอร์ชันนี้รับภาพจาก **Sony Handycam (FDR-AX55)** เป็นวิดีโอ แล้ว "จับเฟรม" เป็นรูป
(ไม่มี SDK สั่งชัตเตอร์ของ Handycam) ส่วนเวอร์ชัน DSLR (Canon EDSDK) ยังไม่ได้ทำ

```
Handycam ──HDMI──► Capture Card (UVC) ──USB──► PC
                                            │  เบราว์เซอร์ (Chrome/Edge): getUserMedia
                                            │  → WebGL ตัดพื้นเขียว → ฉากหลัง → ลายน้ำ → JPG
                                            ▼
                          เซิร์ฟเวอร์ Node (server/): คิว · ภาพ · ฉากหลัง · หน้าดาวน์โหลดมือถือ
                                            ▼
                               มือถือสแกน QR (วง LAN เดียวกัน)
```

## ใช้งาน

ต้องมี Node.js 18+

```bash
npm install
npm run dev          # พัฒนา: เว็บที่ http://localhost:5173  (API พอร์ต 8787)
# หรือใช้งานจริง
npm run build && npm start   # ทุกอย่างที่ http://localhost:8787
```

- ภาพ คิว และฉากที่อัปโหลดเก็บในโฟลเดอร์ `data/` (เปลี่ยนด้วย `DATA_DIR`, พอร์ตด้วย `PORT`) — สำรองโฟลเดอร์นี้เอง
- เปิดผ่าน `localhost` หรือ https เท่านั้น เบราว์เซอร์จึงอนุญาตให้ใช้กล้อง
- **QR:** มือถือต้องเปิดลิงก์ได้ ไปที่ หลังบ้าน → กล้อง → "ที่อยู่เซิร์ฟเวอร์ใน QR" แล้วใส่ IP ของเครื่องในวง LAN เช่น `http://192.168.1.10:8787`
  (เซิร์ฟเวอร์พิมพ์ IP ในวง LAN ตอนเริ่มทำงาน และอาจต้องเปิดพอร์ตใน Windows Firewall)
- ไม่มีกล้อง? ระบบเข้า "โหมดสาธิต" อัตโนมัติ ใช้ฝึกเจ้าหน้าที่ได้ · เติม `?nav=1` ที่ URL เพื่อแสดงแถบข้ามหน้า

## การไหลของหน้าจอ

ต้อนรับ → เลือกฉาก → ถ่ายภาพ (เจ้าหน้าที่กดปุ่มหรือ Space) → พรีวิว → ถ่ายครบ (รหัสคิว, กลับหน้าต้อนรับเองใน 15 วินาที)
จุดรับภาพ (กรอกรหัส 4 หลัก เลือกภาพ สแกน QR) · หน้ามือถือ `#/m/<รหัส>` · หลังบ้าน (ฉาก ลายน้ำ การตัดภาพ ความสมจริง กล้อง)

## ตั้งค่า Handycam หน้างาน

- ใช้ไฟ AC ปิดโหมดประหยัดพลังงาน
- ปิดข้อมูลบนจอที่ออกทาง HDMI (Clean HDMI) ไม่เช่นนั้นจะติดในภาพ — **ต้องเช็กเมนูของรุ่นจริง**
- โหมดแมนนวล ชัตเตอร์ ≥ 1/125 ล็อก White Balance/Exposure
- ไฟฉากเขียวสม่ำเสมอ คนยืนห่างฉาก 1–1.5 ม.
- ขนาดรูปที่ได้ = ความละเอียดวิดีโอที่ Capture Card ส่งมา (1080p → 1620×1080, 4K → 3240×2160) ไม่ใช่ 16.6 MP ของโหมดถ่ายนิ่งในกล้อง

## สถานะ / ข้อจำกัดที่รู้

- ทดสอบกับกล้องจำลองของ Chromium และโหมดสาธิตเท่านั้น **ยังไม่ได้ทดสอบกับ FDR-AX55 และ Capture Card จริง**
- การตัดแบบ "AI" และ "ผสม" ในหลังบ้านยังไม่เปิดใช้ ระบบใช้ Chroma Key เสมอ
- ฉากหลังเริ่มต้นเป็นภาพไล่สีชั่วคราว และชื่อสถานที่เป็นชื่อสมมติ — อัปโหลดภาพจริงและตั้งชื่อใหม่ที่ หลังบ้าน → ฉากหลัง
- หลังบ้านยังไม่มีรหัสผ่าน (ใครแตะปุ่ม "เจ้าหน้าที่" ก็เข้าได้) และเซิร์ฟเวอร์ไม่มีการยืนยันตัวตน ใช้ในวง LAN ที่เชื่อถือได้เท่านั้น
- ลิงก์ดาวน์โหลดยังไม่หมดอายุ (แบบเดิมระบุ 30 วัน) และ "ดาวน์โหลดทั้งหมด" โหลดทีละไฟล์ ไม่ใช่ ZIP
